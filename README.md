# 축구 생활 · Football Life

2000년, 중학교 3학년부터 시작하는 축구 선수 커리어 게임입니다. 재능과 아키타입을 정하고, 훈련·출전·진학·이적을 통해 한 선수의 커리어를 이어갑니다.

## 플레이

GitHub Pages 공개 주소: [축구 생활](https://ryukkani.github.io/Football-life/)

- 스트라이커, 윙어, 미드필더, 센터백, 풀백, 골키퍼의 6개 포지션
- 2000년과 2000/01 시즌을 기준으로 구성한 대한민국·잉글랜드·이탈리아·프랑스·독일·스페인의 104개 구단
- 실제 학교를 바탕으로 한 유소년 토너먼트, 고교 진학과 드문 해외 유스 제안
- 여름·겨울 이적시장, 소집 수락·거절과 U17·U20·U23·성인 대표팀
- 대표팀 예선·본선, 국내 컵과 이전 시즌 리그 성적으로 출전하는 대륙대항전
- 감독 전술과 주전 경쟁, 이적 제안 비교, 부상 재활과 중요한 경기의 선택
- 최근 5시즌 능력·기록 비교
- 시즌 개인 시상, 성적과 선정 기준을 확인하는 수상 내역, 팀 트로피
- 재능 10종, 아키타입 13종, 자동 습득 플레이스타일 36종과 플레이스타일+
- 개인 클럽하우스의 카드·목록, 포지션·소속팀 필터, 전성기 정렬과 두 선수 비교
- 실제 기록에서 모으는 커리어 이정표와 소속팀 색상·로고를 담은 선수 카드
- 보관한 전성기 선수들의 베스트11, 기본 선수 보충과 컴퓨터 구단 친선전

기록은 브라우저에 저장됩니다. 설정에서 **기록 파일 저장 / 불러오기**를 사용할 수 있습니다. 큰 기록은 내용을 보존하면서 자동 압축하며 이전 형식 백업도 읽습니다. 기존 HTML 게임에서 만든 백업을 새 사이트로 옮길 때도 이 기능을 사용하세요. 현재 선수와 다른 기록을 가져오면 현재 선수는 보관 기록에 남습니다.

## 이번 변경

1.5.1은 배경음악을 4곡에서 18곡으로 늘립니다. 홈·클럽하우스 2곡, 중학교·고등학교·국내 구단·국가대표 각 3곡, 해외 구단 4곡을 무대에 맞게 이어 재생합니다. 설정에서 다음 곡으로 넘기거나 음악 모음에서 곡을 직접 골라 듣습니다. 게임으로 돌아가면 해당 무대의 음악으로 복귀합니다.

1.5.0은 클럽하우스에 선수 모음, 두 선수 비교, 커리어 이정표, 베스트11을 추가합니다. 선수 카드는 소속팀 색상·로고·등번호를 담고 앞면과 뒷면을 나눕니다. 생성·새 시즌 프로필, 은퇴와 보관 선수 카드에 같은 디자인을 적용합니다.

베스트11은 4-3-3, 4-4-2, 3-4-3으로 편성합니다. 같은 선수의 서로 다른 백업은 한 명으로 취급하고, 부족한 자리는 기량 60의 기본 선수로 채웁니다. 컴퓨터 구단 친선전은 별도 난수와 기록을 사용하며 실제 커리어의 성적·성장·수상·다음 경기 결과에 영향을 주지 않습니다. 최근 20경기를 보관하고 백업 파일에 편성과 함께 포함합니다.

경기 전환은 기존 4초를 유지하면서 실제 슈팅 계산의 득점 시점과 점수판을 연결했습니다. 선수 성적과 경기 경험으로 얻은 능력 변화는 따로 펼쳐봅니다. 반기 기록은 포지션별 핵심 성적·평점·종합 능력을 먼저 보여주며 수상·스카우팅·제안은 기존의 별도 단계로 유지합니다. 이전 경기의 미기록 득점 시간이나 세부 성장은 추정해 채우지 않습니다.

1.4.3의 공격수 슈팅·득점 균형과 플레이스타일 보정, 시즌 개인 시상은 유지합니다. 기존 커리어와 기록은 다시 계산하지 않습니다.

세부 능력치를 경기 행동의 성공 확률에 연결했습니다. 골 결정력과 평정심은 슈팅·득점, 패스와 시야는 패스 성공·도움, 수비 능력은 태클·가로채기, 골키퍼 능력은 선방·볼 처리에 반영됩니다. 상대 전력과 출전 시간, 컨디션, 체력도 영향을 줍니다.

훈련과 경기 경험을 실제로 진행한 기간만큼 적용합니다. 부상 선수는 회복까지 결장하며 훈련 성장량도 줄어듭니다. 피지컬은 30세, 기술은 33세, 판단은 36세부터 감소하고 유지 훈련은 하락 속도를 늦춥니다. 반기 결과에서 훈련·클럽 경기·대표팀 경기·노화의 변화를 각각 확인할 수 있습니다.

메인 메뉴를 경기장 배경과 중앙 로고, 이어하기와 새 커리어 버튼, 5개 하단 메뉴로 구성했습니다. 내부 화면은 훈련·일정·특성을 나누고, 결과 확인과 제안 선택을 별도 단계로 유지합니다.

계산식과 성장 가중치는 [게임 규칙](docs/game-rules.md), 이미지와 데이터의 출처는 [자료 출처](docs/credits.md)에 정리했습니다.

## 개발과 검증

외부 패키지 설치가 필요 없는 HTML/CSS/JavaScript 프로젝트입니다. Node.js 22 이상을 사용합니다.

```sh
npm run check
npm test
npm run build
```

`index.html`이 사이트 진입점입니다. `src/game-data.js`는 능력치와 성장 가중치, `src/game-engine.js`는 경기·성장·부상, `src/game-expansion.js`는 컵대회·대표팀 본선·선택, `src/game-collection.js`는 저장 선수·이정표·베스트11·친선전, `src/game-save.js`는 기록 파일 검증, `src/game-ui.js`는 화면을 담당합니다.

`npm run build`는 이미지와 스크립트를 포함한 단일 오프라인 파일 `dist/football-life.html`을 만듭니다. 웹사이트는 별도 빌드 없이 루트의 `index.html`과 상대 경로 파일로 실행됩니다.

테스트는 기록 간 일관성, 능력치별 평균 성과 차이, 부상과 결장, 나이에 따른 성장·감소, 완주 가능한 6개 포지션 커리어, 저장·불러오기·삭제, 결과와 제안 화면 분리를 확인합니다. 화면 테스트는 경량 문서 모형을 사용하므로 실제 브라우저의 시각 검증과는 구분합니다.

## 1.2.2 화면과 소리

- 결과 연출은 완료 표시를 포함해 4초 동안 진행하며, 결과 바로 보기로 건너뛸 수 있습니다. 움직임 줄이기를 사용해도 표시 시간은 유지됩니다.
- 메인 제목 옆 축구공 장식을 없애고 소개를 “2000년, 축구 인생이 시작된다.”로 바꿨습니다.
- 선수 프로필은 최초 생성과 새 시즌 시작에만 표시합니다. 국내와 유소년·대학·실업 무대는 1월, 해외 프로는 여름 이적시장인 7월에 새 시즌을 준비합니다. 중간 반기의 잔류·이적 선택은 저장 후 훈련으로 바로 이어지며, 저장 실패 시 기존 기록과 제안을 보존합니다.
- 새 선수 생성과 시즌 시작 프로필 준비는 해당 선수의 연도·소속팀·음악을 표시하며, 프로필을 확인하기 전까지 기존 커리어를 보존합니다.
- 버튼과 펼치기 항목에 작은 눌림 효과를 적용했습니다. 움직임 줄이기에서는 이 효과가 꺼집니다.
- 중학교 16곳·고등학교 8곳의 실제 교표와 2000 시즌 프로 구단 104곳의 실제 엠블럼을 표시합니다. 확보 가능한 현재 표장을 사용하므로 당시 표장과 차이가 있을 수 있습니다.
- 설정에서 전체 음소거, 배경음 음량, 버튼 효과음 음량을 따로 조절합니다. 소리 설정은 선수 기록과 별도 키에 저장합니다.
- 배경음악은 이 게임을 위해 만든 오르골 연주 18곡입니다. 국내 대학·실업·프로 무대에도 별도 재생 목록을 사용합니다. 첫 버튼 조작 후 재생되며, 다른 탭으로 이동하면 멈춥니다. 기존 음소거·배경음·효과음 설정을 유지합니다.

원본 로고 출처는 [추가 팀 표장](docs/team-crest-sources.json)에, 음악 구성과 이용 방식은 [자료 출처](docs/credits.md)에 기록했습니다.

## GitHub Pages 설정

저장소 **Settings → Pages → Build and deployment**에서 `Deploy from a branch`, `main`, `/ (root)`를 선택하고 저장합니다. 별도 API 키나 서버는 필요하지 않습니다. 공개 후 브라우저에서 메인 화면과 새 커리어 진행을 확인하세요.

검증 작업은 `.github/workflows/check.yml`에 포함했습니다. `main` 변경과 Pull Request마다 코드·기록·패키지 검사를 실행합니다. 사이트 공개 자체는 Pages의 브랜치 설정을 사용합니다.

## 기록 호환과 범위

기존 저장 키 `this-life-football-v2`를 유지합니다. 기존 기록을 다시 계산해 덮어쓰지 않으며, 새 반기부터 새 성장 규칙을 적용합니다. 기존 진행 중 반기의 능력 비교 기준은 새로운 종합 능력 계산에 맞춰 변환하고 이전 기준도 저장합니다.

실제 구단과 학교를 바탕으로 구성했지만 경기 결과와 우승, 전력, 계약 조건은 게임 규칙입니다. 역대 실제 결과를 재생하지 않습니다. 유소년·클럽 컵·대표팀 본선의 참가 규모와 대진, 일정은 축약했습니다. 승강제와 계정 간 동기화는 포함하지 않습니다.

## 1.4.0 대회와 커리어 선택

- 월드컵·아시안컵·유로·올림픽·U17/U20 월드컵: 3경기 예선, 조별리그와 토너먼트, 소집 수락·거절, 대회 우승 기록
- 6개 국가의 국내 컵, 유럽·아시아 대륙대항전: 이전 시즌 리그 순위로 출전권 결정, 최초 기록이 없는 시즌에는 구단 전력 기준
- 감독 성향과 포메이션, 같은 포지션의 경쟁 기량, 최근 평점·전술 적합도를 실제 선발 확률에 반영
- 이적 제안의 연봉·역할·출전 시간 전망·전술·경쟁·시설 성장 보너스 비교
- 충분한 재활·예정대로 복귀·빠른 복귀: 회복 날짜와 재부상 위험, 회복기 경기력에 적용
- 준결승·결승·승부차기에서 포지션별 플레이 선택: 능력과 체력으로 성공 여부를 계산하고 실제 경기 계산에 반영
- 최근 5시즌 종합 능력·평점·포지션 기록 그래프: 과거에 저장하지 않은 능력은 미상으로 표시

결과 확인과 다음 선택은 별도 화면으로 유지합니다. 승부차기는 이미 치른 정규시간 기록을 갱신하며 출전·분량·성장 보상을 중복 지급하지 않습니다. 컵 기록은 전체 클럽 기록에 포함하지만 리그 개인 순위와 시상에서는 제외합니다. 선택과 결과는 기존 저장·백업 기능으로 보존하며 저장 실패 시 변경을 되돌립니다.

로그인·휴대폰/PC 온라인 이어하기·친구 비교는 후속 작업으로 남겨둡니다. 고정 라이벌과 선수 세대교체는 추가하지 않았습니다.
