# 경기와 성장 규칙 · 1.1.0

아래 수치는 축구 생활의 게임 규칙입니다. 참고 빌더의 실제 경기 엔진이나 공식 선수 평가를 재현한 값은 아닙니다.

## 종합 능력과 출전

종합 능력은 세부 능력치와 포지션별 가중치의 곱을 합한 뒤 반올림합니다. 전체 가중치는 `src/game-data.js`의 `OVERALL_WEIGHTS`에 있으며 합계는 1입니다. 선수 화면의 **종합 능력 계산**에서도 비중을 확인할 수 있습니다.

| 포지션 | 크게 반영되는 능력 |
| --- | --- |
| 스트라이커 | 골 결정력, 공격 위치선정, 속도, 평정심 |
| 윙어 | 속도, 드리블, 민첩성, 패스, 골 결정력 |
| 미드필더 | 패스, 시야, 드리블, 평정심, 체력 |
| 센터백 | 수비 이해도, 태클, 가로채기, 점프, 힘 |
| 풀백 | 태클, 속도, 수비 이해도, 가로채기, 패스, 체력 |
| 골키퍼 | GK 반응속도, GK 위치선정, GK 다이빙, GK 핸들링, GK 킥 |

종합 능력은 컨디션과 관계없이 선수의 기량을 표시합니다. 경기 능력은 컨디션·사기·체력으로 보정하고, 출전 선택은 팀 전력과 구단 신뢰를 추가로 반영합니다. 선발, 교체, 벤치 대기, 부상 결장, 징계 결장을 구분합니다. 선발 수는 실제 선발 여부를 합산하며, 경기 중 부상이나 퇴장이 생기면 실제 출전 시간을 줄입니다.

경기 행동에도 체력·컨디션·사기 보정이 적용됩니다. 낮은 체력은 패스·슛·수비·선방의 성공 확률을 낮춥니다. 경기 사이 실제 날짜 차이에 따라 체력이 회복되며 2배 훈련과 높은 나이는 회복 속도를 낮춥니다.

## 경기 행동에서 기록으로

팀의 슈팅 수를 공격·수비 전력과 홈 이점으로 뽑고, 각 슈팅에 발생 시각을 부여합니다. 선수가 실제로 뛰는 시간에 발생한 행동만 개인 기록으로 남습니다.

선수의 유효 슈팅 확률에 사용하는 능력은 골 결정력 60%, 평정심 25%, 공격 위치선정 15%입니다. 득점 전환은 골 결정력 65%, 평정심 20%, 공격 위치선정 15%와 상대 골키퍼 전력의 차이를 반영합니다. 포지션과 공격 위치선정·속도·드리블·전술 성향으로 개인 슈팅 비중을 정합니다. 능력치가 높아도 모든 경기에 같은 결과를 보장하지는 않습니다.

1.4.2부터 사용자 팀과 다른 팀, 클럽 컵과 대표팀에 같은 슈팅·득점 계산을 사용합니다. 팀 슈팅의 평균은 `10.5 + (공격 전력−수비 전력) × 0.12 + 홈/원정 보정`이며 4.5~17 범위입니다. 홈은 +0.75, 원정은 −0.40, 중립은 0입니다. 개인 슈팅 비중은 ST 30%, WG 22%, MF 14%, CB 4.5%, FB 7%, GK 0%를 기준으로 동료 대비 공간 침투 능력·플레이스타일·전술을 반영하고 최대 45%입니다. 출전하지 않는 시간에는 동료가 슈팅합니다.

유효 슈팅 확률은 `0.34 + (슈팅 정확도−상대 수비 전력) × 0.0025`를 20~50%로 제한한 값입니다. 유효 슈팅의 득점 확률은 `0.33 + (마무리 능력−상대 골키퍼 전력) × 0.0035`를 10~55%로 제한한 값입니다. 득점 플레이스타일 효과는 선수 자신의 마무리에만 추가되며 기존 효과 합산값의 35%, 최대 30% 보너스입니다. 기본 특성이 충분히 쌓인 공격 성향의 양발 선수도 플레이스타일+를 선택하면 추가 마무리 효과를 받습니다. 팀 전체에 중복 적용하지 않습니다. 개인 득점을 시즌 총량으로 잘라내는 방식이 아니므로 뛰어난 선수의 다득점과 드문 해트트릭은 가능합니다.

| 행동 | 주요 능력 및 연결 |
| --- | --- |
| 패스 성공 | 필드 선수는 패스 70%, 평정심 20%, 시야 10%. 골키퍼는 GK 킥 50%, 패스 30%, 시야 20% |
| 도움·기회 창출 | 시야·패스·평정심. 본인이 넣지 않은 출전 중 팀 득점에서 도움 배정 |
| 드리블 성공 | 드리블 50%, 민첩성 30%, 밸런스 20% |
| 태클 성공 | 태클 50%, 수비 이해도 20%, 힘 15%, 반응속도 15% |
| 가로채기 | 가로채기 65%, 수비 이해도 20%, 반응속도 15% |
| 선방 | GK 반응속도 32%, GK 다이빙 23%, GK 위치선정 25%, GK 핸들링 20% |
| 공 잡기 | GK 핸들링 65%, GK 위치선정 25%, 힘 10% |

기록은 다음 관계를 만족합니다.

- 개인 득점 ≤ 개인 유효 슈팅 ≤ 개인 슈팅
- 개인 득점 + 도움 ≤ 팀 득점
- 성공 패스 ≤ 시도 패스, 성공 드리블 ≤ 시도 드리블, 성공 태클 ≤ 시도 태클
- 골키퍼 선방 + 출전 중 실점 = 출전 중 상대 유효 슈팅
- 무실점 출전은 60분 이상 뛰고 출전 중 실점이 없는 경기
- 출전하지 않은 선수의 개인 행동 기록과 평점은 0

평점은 포지션별 결과를 반영합니다. 공격수는 골·도움·기회 창출, 수비수는 태클·가로채기·무실점, 골키퍼는 선방률·선방·볼 처리·실점이 중심입니다. 모든 포지션에서 경기 결과와 퇴장도 영향을 줍니다. 반기 평균 평점은 실제 출전 경기만 합산합니다.

## 훈련 성장

훈련을 선택해 진행하면 계획이 고정됩니다. 성장량은 실제 지나간 날짜에 연간 성장 기준을 비례 적용합니다. 반기 시작 버튼을 눌렀다고 전체 반기의 성장량을 미리 주지 않습니다.

| 나이 | 피지컬 연간 기준 | 기술 연간 기준 | 판단 연간 기준 |
| --- | ---: | ---: | ---: |
| 21세까지 | 3.2 | 2.2 | 1.4 |
| 22~29세 | 0.45 | 2.0 | 1.4 |
| 30세부터 | 0 | 0.25 | 1.15 |

각 수치는 능력치 하나의 기본 성장 기준입니다. 훈련 강도, 타깃, 집중 육성, 아키타입, 재능, 체력, 부상과 구단 훈련 지원을 함께 적용하므로 실제 결과는 달라집니다. 33세부터 기술, 36세부터 판단의 양수 성장은 중단됩니다.

- 강도 성장 계수: 최소 0.6, 보통 1, 2배 훈련 1.65. 부상 위험의 훈련 부하 계수는 각각 0.5, 1, 2입니다.
- 전문 훈련은 대상 능력 1.65배, 나머지 0.65배. 종합 훈련은 전체 1배입니다.
- 집중 육성은 최대 2개, 해당 능력 1.25배. 아키타입 핵심 능력은 1.12배입니다.
- 빠른 성장 재능은 1.25배입니다. 모든 선수의 상한은 99입니다. 소수점 종합 능력 90부터 양수 성장에 `(99 − OVR) / 9`를 곱하고, 최소 계수는 0.08입니다. 능력치 99에는 추가 성장을 주지 않습니다.
- 약발 훈련은 다른 능력 훈련을 35%로 줄입니다. 약발은 건강한 훈련 1년 기준 45를 강도에 맞춰 올리고, 숙련도 85부터 양발 활용 효과를 적용합니다.

경기 경험은 출전 시간과 실제 행동으로 별도 계산합니다. 패스 성공은 패스, 슛·득점은 골 결정력과 위치선정, 태클은 태클, 선방은 골키퍼 능력 등에 조금씩 반영합니다. 벤치 대기에는 경기 성장량이 없습니다. 아키타입 레벨 상승 자체는 무료 능력치를 주지 않습니다.

## 부상과 감소

경기 부상 확률은 기본 1.2%에 훈련 부하, 피로, 29세 이후 나이, 체력·밸런스·힘, 철인 재능을 반영합니다. 실제 출전 시간만큼 위험에 노출됩니다. 훈련 중에도 낮은 확률로 부상이 발생합니다.

| 부상 | 회복 기간 | 종류 선택 비중 |
| --- | --- | ---: |
| 발목 염좌 | 7~24일 | 45% |
| 근육 부상 | 10~35일 | 34% |
| 햄스트링 부상 | 21~56일 | 17% |
| 무릎 부상 | 60~120일 | 4% |

회복까지 결장하고 그 기간에는 신체·기술 훈련을 정상의 8%, 판단 훈련을 65%만 반영합니다. 부상 기간이 겹쳐도 같은 날짜를 중복 차감하지 않습니다. 부상과 회복 날짜는 저장·불러오기 후에도 유지됩니다.

능력치 하나당 연간 감소 기준은 다음과 같으며, 실제 경과 일수에 비례합니다.

- 피지컬, 30세부터: `0.75 + (나이−30) × 0.22`
- 기술, 33세부터: `0.22 + (나이−33) × 0.15`
- 판단, 36세부터: `0.15 + (나이−36) × 0.14`

훈련 대상 피지컬의 감소량은 58%, 기술은 80%로 완화합니다. 유지 훈련을 해도 감소가 완전히 사라지지는 않습니다. 능력치의 최저값은 10입니다.

## 기록과 저장

### 대표팀과 국적

대표팀 소집은 U17(15~17세), U20(18~20세), U23(21~23세), 성인(24세 이상)으로 나눕니다. 18세 이상이며 성인 선발 기준보다 종합 능력이 7 높으면 일찍 성인 대표팀에 발탁될 수 있습니다. 소집 화면에서 국가, 연령별 대표팀, 친선 경기 구분을 표시합니다. U23 등을 성인 A매치로 집계하지 않습니다.

소집 제안은 반드시 수락하거나 거절해야 합니다. 제안 중에는 경기가 진행되지 않습니다. 친선 소집은 두 경기를, 공식 대회 소집은 해당 창의 예선 또는 본선 경기를 치른 뒤 같은 클럽 진행 시점으로 복귀합니다. 거절하면 선수의 출전 기록을 추가하지 않고 대표팀 경기는 팀 단위로 진행합니다. 거절에 대한 신뢰·사기 감소는 없습니다. 제안, 응답, 결과를 저장하여 같은 날짜의 제안이나 이미 치른 경기를 새로 계산하지 않습니다. 부상 중이거나 현역 복무 중이면 소집되지 않습니다. 유소년·대학·실업·프로에서도 연령과 기량 기준을 충족하면 소집될 수 있습니다.

선수 → 대표팀에서 보유 국적과 대표팀 국가를 확인합니다. 시작 국적은 대한민국입니다. 해외 구단의 소속 국가와 선수의 국적은 별도로 관리합니다. 게임 기준으로 18세 이후 같은 나라에서 5년 연속 활동하면 해당 국적을 선택하여 추가할 수 있습니다. 영국(잉글랜드 대표팀)·이탈리아·프랑스·독일·스페인이 대상입니다. 같은 나라 안의 이적·임대는 기간을 유지하고, 다른 나라로 옮기면 기간을 다시 계산합니다. 부상은 소속 국가의 활동 기간을 끊지 않습니다. 취득해도 대표팀 국가가 자동으로 바뀌지는 않습니다.

대표팀은 친선 경기와 공식 대회를 구분합니다. 기존 대표팀에 실제 출전한 뒤의 국가 변경은 게임에서 한 번만 허용하며, 변경 전 경기 기록은 국가·연령별로 그대로 남깁니다. 다른 국가의 **성인 공식 대회** 출전이 있으면 변경을 허용하지 않습니다. 연령별 공식 대회는 이후 한 번의 변경을 막지 않습니다. 예전 버전의 대표팀 경기는 기존 대한민국 성인 친선 A매치로 옮기고, 예전 해외 활동은 저장된 소속팀 이력과 기간으로 계산합니다.

국적 취득과 대표팀 자격·변경을 구분하는 구조는 [FIFA 대표팀 자격 안내](https://inside.fifa.com/legal/news/updated-documentation-guidance-player-eligibility-change-association)를 참고했습니다. 활동 5년·국적 추가·국가 변경 1회는 이 게임의 단순화한 규칙이며, 국가별 시민권 법률이나 실제 FIFA 변경 심사를 재현하지 않습니다.

클럽 반기 합계는 경기 기록을 합산한 값입니다. 국가대표 경기 기록은 클럽 합계에 포함하지 않습니다. 국가대표 출전 경험은 별도 성장 원인으로 남습니다. 저장된 난수 상태를 이어 사용하므로 결과·제안 화면을 다시 열거나 새로고침해도 이미 치른 결과는 바뀌지 않습니다.

옛 경기에는 새 항목을 임의로 만들어 넣지 않습니다. 세부 기록은 `modelVersion: 3` 이상인 경기부터 표시하며 1.4.2의 경기 계산은 `modelVersion: 4`입니다. 새 계산은 업데이트 후 진행하는 경기부터 적용합니다. 과거 득점·평점·수상은 그대로 보관하며, 진행 중 훈련을 다시 지급하지 않습니다. 기존 기록을 불러오면 진행 중인 선수와 보관 기록을 병합하며, 저장 실패 시 불러오기와 삭제를 취소합니다.

## 구단 환경과 재능

시설과 코칭은 구단 전력과 학교/대학/프로 구분으로 정한 게임 내 1~5등급입니다. 실제 시설 평가 자료는 아닙니다. 시설 한 등급에 3.5%, 코칭 한 등급에 2.5%의 훈련 성장을 더합니다. 경기 경험 성장에는 시설 보너스를 적용하지 않습니다. 대기만성은 시작 능력 −4, 22세부터 훈련·경기 성장 20% 보너스입니다. 침착함은 평정심 +4와 함께 센터백·풀백 태클, 골키퍼 위치선정, 나머지 포지션 골 결정력을 +4 합니다.

## 역할, 목표와 감독 면담

주전/로테이션/유망주는 선발 확률에 각각 +0.055/+0.025/0을 더합니다. 반기 목표는 역할별 예상 출전 시간과 포지션 기록으로 정합니다. 부상 기간에 비례하여 목표를 낮추고, 달성 항목마다 구단 신뢰 +3을 줍니다. 부상 없이 놓친 목표는 항목마다 −1입니다. 출전 기회 요청은 현재 기량, 신뢰, 부상을 확인해 역할을 올리거나 거절합니다. 회복 상담은 체력 +8과 최소 강도 계획으로 연결됩니다.

## 계약과 임대

프로 계약 제안마다 1회 연봉 +10%/+20%, 24/36/48개월과 역할을 협상할 수 있습니다. 현재 기량, 최근 평점, 신뢰, 요구 수준으로 성공 확률을 계산하고 동일 제안의 결과는 저장합니다. 성공 시 전부 달성한 반기에 연봉의 반기 비중 × 8% 목표 보너스를 지급합니다. 실패해도 원래 제안은 유지하며 현재 구단 협상 실패에는 신뢰 −3, 모든 실패에는 사기 −3을 줍니다.

임대는 잔여 계약 이내의 6개월 또는 12개월입니다. 원소속, 연봉, 계약 조건을 보관하고 임대 구단의 경기와 시설을 적용합니다. 계약은 계속 줄고, 종료 이적시장에 원소속으로 자동 복귀합니다. 임대 중 재임대/이적/복무는 제한합니다. 경기 기록은 실제 뛴 팀별로 남습니다.

## 대학, 실업팀, 입단 테스트

고교·유스 졸업 후 실제 축구부가 있는 대학 6곳과 실업팀을 선택할 수 있습니다. 대학은 4년 과정이며 2년 이상 재학하거나 OVR 65에 도달하면 프로 제안이 추가됩니다. 4년 후에는 졸업하여 프로/실업팀 경로를 선택합니다. 실업팀 OVR 57부터 프로 제안이 추가됩니다. 18~25세의 졸업 선수와 대학/실업 선수는 해외 테스트 기회를 받을 수 있습니다. 테스트는 현재 경기 능력과 저장된 평가 편차를 구단 기준과 비교하여 한 번 평가합니다. 팀 구성·전력·대학/실업 리그 일정은 게임용이며 실제 2000년 리그나 당시 선수 명단을 재현하지 않습니다.

## 개인 순위와 시상

각 프로 구단에 가상의 선수 18명을 생성합니다. NPC 기록은 이미 계산한 팀 스코어 안에서 개인 득점과 도움을 배분하고, 사용자 출전 분량을 같은 포지션 NPC에서 뺍니다. 사용자의 순위에는 실제 리그 경기 기록만 사용합니다. 컵대회와 대표팀 기록은 포함하지 않습니다. 별도 고정 시드로 처리하여 순위·수상 화면을 열어도 다음 경기 결과가 바뀌지 않습니다. 사용자와 NPC 평점은 같은 포지션별 평가식을 사용하며, 새 NPC 골키퍼의 상대 유효 슈팅도 실제 팀 슈팅 결과에서 집계합니다.

득점왕은 최다 골, 도움왕은 최다 도움입니다. 시즌 MVP는 시즌 평균 평점, 최우수 골키퍼는 선방률로 선정합니다. MVP·최우수 골키퍼·베스트11에는 그 리그 경기 시간의 40% 이상 출전을 요구하며, 골키퍼는 리그 진행 경기 수에 따른 6~30회 상대 유효 슈팅 표본도 필요합니다. 베스트11은 GK 1명, CB 2명, FB 2명, MF 3명, WG 2명, ST 1명을 포지션별 평점으로 선정합니다. 같은 포지션에서 평점이 같으면 출전 시간을 우선합니다. 득점·도움의 실제 공동 1위는 함께 수상하고, MVP·골키퍼 순위는 표시용 반올림 전의 평균을 비교합니다.

시즌 종료 후 **반기 결과 → 시즌 개인 시상 → 스카우팅 리포트 → 제안 선택** 순서로 진행합니다. 시상 발표도 4초 연출을 사용하고 새로고침 후 같은 결과를 보여줍니다. 커리어의 **수상 내역 보기**에서 개인 수상, 팀 우승, 시즌 전체 수상자를 나누어 확인합니다. 새 수상에는 시즌·구단·출전·분량·포지션 성적·공동 수상 여부와 선정 기준을 함께 보관합니다. 시즌 수상자와 베스트11의 스냅샷은 반기 기록에 남겨, 오래된 리그 데이터를 정리한 뒤에도 확인할 수 있습니다. 옛 수상의 성적은 남아 있는 당시 수상 값과 실제 경기 기록으로 표시하고 과거 수상자를 다시 선정하지 않습니다. 1.4.3부터 옛 시상의 선정 기준은 이전 규칙으로 구분하며, 저장되지 않은 베스트11 평점은 `—`로 표시합니다. 예전 공동 수상도 같은 부문 수상자 목록에서 확인할 수 있습니다.

## 특별훈련과 복무

특별훈련은 반기 1회, 커리어 전체 6회로 제한합니다. 참여를 시작할 때 기회를 소모하고, 슈팅/패스/골키퍼 반응 타이밍의 정확도에 따라 해당 능력 0.1~0.6 성장, 멘토는 나이상 성장 가능한 핵심 능력 중 가장 낮은 항목을 0.4 올립니다. 90 감속과 노화 제한이 적용됩니다. 새로고침으로 중단된 시도에는 보상을 주지 않습니다.

국내 프로/실업 선수는 18~28세에 상무 지원 또는 현역 복무를 선택할 수 있습니다. 상무는 현재 OVR, 최근 평점, 인지도 점수를 가상 경쟁자 11명과 비교하여 상위 4명을 선발하고 연 1회 지원을 허용합니다. 현역은 구단 출전이 없으며 훈련 성장 계수를 0.12로 줄입니다. 두 경로 모두 게임 균형을 위해 18개월로 정하고, 복무 후 원소속으로 복귀합니다. 상무 이름은 2002년까지 상무 축구단, 2003~2010 광주 상무, 2011~2020 상주 상무, 2021년 이후 김천 상무로 표시합니다. 실제 복무 기간·법적 의무·당시 대회 참가 규정을 재현하는 기능은 아닙니다.

## 리포트와 은퇴

한국 무대는 1월, 유럽은 7월 이적시장에 지난 시즌 기록을 합산해 스카우팅 리포트를 만듭니다. 신체, 핵심 능력, 출전과 포지션 기록, 최근 성장과 다음 육성 방향을 실제 저장값에서 작성합니다. 반기 반응은 실제 경기와 목표 달성으로 1~3개만 표시합니다. 은퇴 기념 카드에는 모든 단계의 누적 기록과 전성기 OVR, 최고의 경기, 개인 수상, 우승, 국가대표 기록을 넣습니다. 평가 항목은 전성기 기량/출전과 포지션 기여/개인 시상/팀 우승/대표팀으로 나눕니다. 공격수는 득점·도움, 미드필더는 기회 창출, 수비수는 수비, 골키퍼는 선방·무실점으로 기여를 평가합니다.

## 대표팀 예선과 본선

월드컵은 2002년부터 4년 주기, 유로와 올림픽은 2000년부터 4년 주기, U17/U20 월드컵은 홀수 해에 진행합니다. 아시안컵은 2000·2004년과 2007년부터의 4년 주기로 구성합니다. 게임 일정은 월드컵·유로 6월, 올림픽·연령별 월드컵 7월, 아시안컵 1월 하순으로 축약합니다. 실제 개최 날짜, 취소·연기, 개최국별 규정과 이후 대회 확대를 재현하지 않습니다.

예선은 이전 해 9·10·11월 하순의 4팀 조별 3경기이며 상위 2팀이 본선에 진출합니다. 본선은 16팀(아시안컵 8팀), 4팀씩 3경기 조별리그 후 상위 2팀이 토너먼트에 오릅니다. 지역 대회는 같은 대륙의 국가만 참가합니다. 2002년 대한민국은 개최국 출전권을 적용합니다. 과거에 놓친 예선이나 소집을 거절한 창은 팀 경기만 계산하며 선수의 출전은 만들어 넣지 않습니다.

공식 성인 대회는 18세 이상, U17은 17세까지, U20은 18~20세, 올림픽 U23은 23세까지 참가할 수 있습니다. 23세를 넘은 선수는 성인 선발 기준보다 OVR이 7 이상 높으면 게임 내 와일드카드 소집 대상입니다. 전체 선수 명단과 실제 와일드카드 3명 경쟁은 재현하지 않습니다. 참가 연령과 국가를 경기 기록에 남겨 성인 A매치·연령별 대표팀 합계를 분리합니다.

## 클럽 컵과 대륙대항전

프로 구단의 국내 컵은 해당 국가의 게임 내 1부 구단이 참가하는 단판 토너먼트입니다. 참가 수가 부족하면 부전승을 배정하며 부전승에 출전·경기 경험을 지급하지 않습니다. 유럽 대륙대항전은 16팀, 아시아는 8팀이며 조별 3경기 후 상위 2팀이 토너먼트에 진출합니다.

이전 시즌 리그 순위를 저장하고 잉글랜드·이탈리아·스페인은 상위 4팀, 독일·프랑스는 상위 2팀, 대한민국은 상위 2팀이 대륙대항전에 나갑니다. 아시아에는 일본·서아시아의 실제 6개 구단을 함께 넣었습니다. 이전 순위가 없는 최초 시즌은 구단 전력으로 정합니다. 이 규칙은 게임용이며 당시 UEFA/AFC 국가별 배정, 하부리그 참가팀, 홈·원정 다단계 예선과 그룹 구성은 생략합니다.

아시아 대회는 2002년까지 아시안 클럽 챔피언십, 2003년부터 AFC 챔피언스리그로 표시합니다. 명칭 변화는 [AFC의 대회 연혁](https://www.the-afc.com/en/club/afc_champions_league/news/afc_champions_league_through_the_years_2003-06.html)을 참고합니다. [UEFA의 당시 형식 안내](https://www.uefa.com/news-media/news/0180-0f84343cda46-ef45a4d9e8e2-1000--uefa-to-keep-current-uefa-champions-league-format/)에 있는 두 차례 조별리그를 그대로 구현한 형식은 아닙니다.

컵 경기는 리그와 같은 능력·체력·부상·출전 계산을 사용합니다. 전체 클럽 합계·시즌 리포트에는 포함하지만 리그 개인 순위·리그 시상에는 섞이지 않습니다. 우승과 기여 출전이 함께 있어야 선수의 우승 트로피를 지급하며, 새로고침·반기 변경 뒤에도 중복 지급하지 않습니다.

## 감독 전술과 이적 비교

구단별 감독 성향과 포메이션, 포지션별 자리와 경쟁 기량을 고정한 뒤 선수의 현재 OVR·최근 5경기 평점·전술 적합도로 선발 확률 보정(−20~+18%p)을 계산합니다. 기존 체력·컨디션·신뢰·계약 역할도 함께 적용합니다. 포지션 자리가 적거나 경쟁 기량보다 낮거나 체력이 부족한 경우 화면에 이유를 표시합니다. 감독 전술·경쟁 기량을 확인해도 다음 결과에 쓰는 난수는 소모하지 않습니다.

이적 비교는 제안 구단의 감독·포지션 경쟁·제안 역할을 기준으로 연봉과 예상 출전 시간, 전술 적합도, 시설·성장 보너스를 표시합니다. 출전 전망은 보장된 출전량이 아니며 부상과 경기력에 따라 달라집니다. 전술 성향은 반기 훈련 시작 전에 변경할 수 있습니다. 고정 라이벌과 선수 세대교체는 포함하지 않습니다.

## 복귀 계획과 중요한 경기의 선택

부상 후 남은 회복 일수에 대해 충분한 재활은 120%, 예정대로 복귀는 100%, 빠른 복귀는 65%를 적용합니다. 빠른 복귀는 최소 1일이며 기존 잔여 일수보다 길어지지 않습니다. 충분한 재활은 회복 뒤 14일간 부상 위험 계수 0.65, 빠른 복귀는 원래 회복 예정일+7일까지 계수 2.2와 경기 능력 −5를 적용합니다. 회복 전에는 여전히 출전할 수 없으며, 선택한 실제 회복 기간으로 훈련 손실을 계산합니다.

중학교·고교·유스 토너먼트와 클럽 컵, 대표팀 대회의 준결승·결승에서는 포지션에 따라 슈팅/패스, 수비 위치 유지/압박, 볼 잡기/펀칭을 고릅니다. 관련 능력·체력·상대 기량으로 성공 확률을 15~88% 범위에서 계산합니다. 성공은 관련 경기 능력 +7, 실패는 −5이며 해당 경기만 적용합니다. 출전하지 않으면 이 보정으로 개인 행동을 만들지 않습니다. 승부차기는 키커의 마무리 방식 또는 골키퍼의 대응 방식으로 한 번의 킥 성공 확률을 보정합니다. 결과를 받은 뒤 스코어를 임의로 더하는 방식은 사용하지 않습니다.

정규시간 동점의 토너먼트는 승부차기 선택 화면으로 넘어갑니다. 이 단계는 이미 치른 90분을 다시 계산하지 않고 기존 경기의 승부차기와 진출 결과만 갱신합니다. 정규시간 출전·분량·경험·성장과 국가대표 캡을 중복 지급하지 않습니다. 선택은 저장되고 실패한 저장은 난수 상태까지 되돌립니다.

## 최근 5시즌 비교와 이전 기록

국가·무대·리그 시즌별로 실제 클럽 경기를 합산해 최근 5시즌을 표시합니다. 종합 능력·평점과 필드 선수의 득점/도움 또는 골키퍼의 선방률/무실점 경기를 비교합니다. 진행 중인 시즌은 현재 능력과 누적 기록, 완료 시즌은 마지막에 저장한 OVR을 사용합니다. 이적한 국가·무대가 다르면 같은 해라도 별도 행으로 표시합니다.

이전 반기의 저장된 종료 OVR은 옮기지만 당시 저장하지 않은 세부 능력치를 현재 수치로 채우지 않습니다. 능력 기록이 없는 시즌은 미상으로 표시합니다. 기존 경기 결과·부상·연봉·국적을 다시 계산하지 않고, 새 대회와 선택부터 기존 저장 키에 이어 기록합니다. 로그인·기기 간 온라인 동기화·친구 비교는 다음 작업으로 남겨둡니다.

## 클럽하우스와 커리어 이정표

현재 선수와 보관 선수는 읽기 전용으로 비교합니다. 카드의 전성기는 저장된 `prime.details`, 반기 종료 능력치와 현재 능력 중 실제로 확인되는 최고 종합 능력을 사용합니다. 예전 기록에 전성기 세부 능력치가 없으면 현재 보관된 기량을 표시하며, 예전 OVR 숫자에 맞춰 능력치를 역산하지 않습니다. 경기 성적은 소속팀 통산 기록입니다. 골키퍼는 선방·무실점, 센터백은 태클·가로채기, 풀백은 도움·태클, 미드필더는 키패스·도움, 공격수·윙어는 골·도움을 대표 성적으로 표시합니다.

이정표는 실제 출전한 경기에서 첫 출전·첫 골·첫 도움·첫 무실점·프로와 해외 데뷔, 소속팀 100/250/500경기, 득점·도움·선방·무실점 누적 기준을 찾습니다. 성인 A매치의 첫 출전과 25/50/100경기는 연령별 대표팀과 구분합니다. 기존 우승·개인 수상과 은퇴도 기록합니다. 결장은 출전 수에 포함하지 않고 통산 합계만으로 이정표를 만들어내지 않습니다. 이전 기록의 이정표는 목록에 표시하며 새로 진행하는 커리어에서 달성한 순간만 새 알림에 추가합니다. 알림을 확인해도 경기 난수나 성적은 바뀌지 않습니다.

## 나만의 베스트11과 친선전

4-3-3, 4-4-2, 3-4-3의 11자리에 같은 포지션의 저장 선수를 배치합니다. 같은 커리어의 백업을 여러 개 가져와도 한 선수는 한 번만 쓸 수 있습니다. 보관 인생을 삭제하면 해당 자리는 기본 선수로 복원됩니다. 기본 선수의 모든 능력치는 60입니다. 편성과 최근 친선전 20경기는 기존 선수 저장 키의 별도 `clubhouse` 항목에 기록하고, 백업·불러오기에도 포함합니다. 이전 형식 백업을 가져오면 현재 베스트11을 유지합니다.

친선전은 커리어 난수와 분리된 전용 난수를 사용합니다. 전성기 포지션 OVR로 공격수·윙어 65%, 미드필더 25%, 수비수 10%의 팀 공격을 계산합니다. 팀 수비는 수비수 평균 55%, 골키퍼의 다이빙·반응·위치선정·핸들링 45%입니다. 상대는 기존 2000/2000–01 구단 데이터의 게임 내 전력을 사용합니다. 양 팀 모두 기존 슈팅·유효 슈팅·마무리 계산을 사용합니다.

팀이 실제로 성공시킨 골을 포지션·골 결정력·공격 위치선정에 따라 득점자에게 배분하고, 시야·패스에 따라 도움을 배분합니다. 골키퍼 선방은 상대 유효 슈팅에서 실점을 뺀 값입니다. 개인 기록은 팀 점수와 일치하며 실제 커리어의 출전·득점·성장·수상·임금·부상·다음 경기에는 반영하지 않습니다. 친선전은 전성기 기량의 전원 90분 경기이며 교체·부상·징계를 따로 발생시키지 않습니다.

## 경기 장면과 결과 표시

4초 전환 중 점수판은 슈팅 계산에서 이미 생성한 실제 득점 시점을 사용합니다. 여러 경기의 반기를 진행하면 실제 새 경기들을 순서대로 표시합니다. 장면 기록 추가를 위해 별도 난수를 사용하지 않으며, 저장 실패 시 전용 친선전 기록을 포함해 되돌립니다. 결과 바로 보기를 눌러도 동일한 결과를 표시합니다.

경기별 경험 성장은 경기 직전·직후 실제 능력치의 차이와 OVR을 기록합니다. 결과는 점수판과 포지션별 핵심 성적·평점을 먼저, 세부 성적·능력 변화·득점 장면은 펼치기 항목으로 표시합니다. 과거 경기의 득점 시간과 개별 성장량이 없는 경우 미기록으로 안내하며 생성하지 않습니다. 승부차기는 완료된 정규시간 점수를 유지하고 4초 뒤 킥 결과를 공개합니다. 반기 결과의 팬 반응·훈련 변화·경기별 기록·세부 통계도 접어 두고 수상과 계약은 다음 단계에서 확인합니다.

## 큰 기록 저장과 백업

기존 저장 키와 기록 내용은 유지합니다. 작은 기록은 기존 JSON 형식이며, 120만 문자 이상의 기록은 UTF-8 gzip 압축이 더 작을 때 `version: 2`, `encoding: fgz1`의 JSON 포장으로 저장·내보냅니다. 경기·세부 능력의 소수점·난수·편성·친선전·기존 세계 데이터를 생략하지 않습니다. 이전 평문 백업도 계속 읽습니다.

가져올 파일은 15MB까지, 압축 해제한 내용은 UTF-8 80MB까지 허용합니다. 잘리거나 잘못된 압축과 유효하지 않은 선수·경기 기록은 현재 저장을 바꾸기 전에 거절합니다. 브라우저의 저장 용량을 넘기는 경우 변경 전체를 되돌립니다. 1.5.0에서 압축한 백업은 이전 버전 게임으로 가져올 수 없으므로 복원에는 최신 버전을 사용합니다.
